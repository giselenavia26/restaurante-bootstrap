Conhecendo o Bootstrap

Documentação e explicação dos conceitos utilizados neste projeto.

O que é Bootstrap?

O Bootstrap é um framework front-end gratuito e open-source amplamente utilizado no desenvolvimento web. Ele disponibiliza um conjunto de estruturas HTML, CSS e JavaScript pré-estilizadas para acelerar a criação de interfaces modernas, organizadas e responsivas.

Para que serve?

Ele resolve o problema de ter que construir toda a estilização e layout do zero. Evita inconsistências visuais entre navegadores, reduz drasticamente o tempo de desenvolvimento e elimina a necessidade de escrever regras CSS complexas para adaptar o site a telas menores.

Sistema de Grid

O sistema de grid do Bootstrap se baseia em uma estrutura flexível dividida em até 12 colunas. Os principais elementos dessa estrutura são:

  • .container: Define a largura máxima do conteúdo e centraliza a página na tela.
  • .row: Cria uma linha horizontal para agrupar e organizar as colunas.
  • .col: Define colunas de largura automática ou proporcional.
  • .col-md-*: Aplica a largura especificada em dispositivos de tamanho médio (tablets em diante).
  • .col-lg-*: Aplica a largura especificada em telas grandes (monitores de computador).

Responsividade

Design responsivo é a técnica que permite a uma página web adaptar seu layout e elementos automaticamente de acordo com o tamanho da tela do usuário. O Bootstrap facilita essa tarefa dividindo as telas em breakpoints:

📱 Celulares
(<576px)
📱 Tablets
(≥768px)
💻 Notebooks
(≥992px)
🖥️ Monitores
(≥1200px)

5 Componentes Utilizados no Projeto

1. Navbar

Barra de navegação superior e responsiva que inclui logotipo, links de navegação e menu estilo hambúrguer para dispositivos móveis.

2. Card

Contêiner flexível usado para exibir conteúdos agrupados visualmente com imagens, títulos, textos e botões.

3. Buttons (Botões)

Classes de estilização rápida para botões com estados interativos, cores padronizadas (ex: btn-warning, btn-danger) e tamanhos flexíveis.

4. Alert

Caixas de aviso para chamar a atenção do usuário com mensagens informativas ou de destaque.

5. Badge

Pequenos destaques visuais (etiquetas) usados para categorizar os itens dentro dos cards.
