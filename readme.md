# Restaurante Sabor & Tradição - Projeto Bootstrap

## 📝 Descrição do Projeto
O **Sabor & Tradição** é um site responsivo de um restaurante fictício desenvolvido como atividade prática para explorar os recursos do framework **Bootstrap 5**. O projeto apresenta a marca do restaurante, seu cardápio com pratos e uma página explicativa sobre as tecnologias utilizadas.

## 🚀 Tecnologias Utilizadas
* **HTML5**: Estruturação semântica do conteúdo.
* **CSS3**: Estilização personalizada complementar.
* **Bootstrap 5 (CDN)**: Framework front-end para layout responsivo, sistema de grid e componentes.
* **GitHub**: Versionamento de código.
* **Vercel**: Hospedagem e publicação da aplicação web.
